## Short description

Shorten the open file in Google Docs™ or create secure links inside Google Workspace™.

## Detailed description

URL Shortener by A.af helps teams turn long URLs into clean, manageable short links without leaving Google Workspace™.

Connect your A.af account once, choose the workspace where the link belongs, and create a short link from the side panel. In Google Docs™, Google Sheets™, and Google Slides™, grant access to the open file to shorten its verified sharing URL in one step. The add-on calls the Google Drive™ API for the current file's link; it does not read file content. You can also paste a destination URL manually in Gmail™, Google Calendar™, and Google Drive™. Every link uses A.af's normal server-side URL validation, workspace permissions, usage limits, duplicate handling, and Trust & Safety controls.

Use A.af links in documents, spreadsheets, presentations, emails, calendar events, campaign workflows, and shared team resources. Created links remain available in your A.af dashboard with their analytics and organization settings.

Google Workspace™, Google Docs™, Google Sheets™, Google Slides™, Google Drive™, Google Calendar™, and Gmail™ are trademarks of Google LLC.

## Key benefits

- Shorten the current Google Docs™, Google Sheets™, or Google Slides™ file after granting access to that file.
- Create A.af links from a pasted URL inside supported Google Workspace™ apps.
- Choose the correct A.af workspace before creating a link.
- Keep link ownership, permissions, limits, and safety checks consistent with the A.af dashboard.
- See whether a link was created through Google Workspace™ in A.af administration analytics.
- Revoke the Google connection at any time.

- Install the unpublished HTTP deployment and test account connection, link creation, workspace selection, and disconnect in a supported Google Workspace™ app.
- Capture at least one real, full-bleed screenshot of the installed add-on in a Google Workspace™ side panel for the listing. Do not use a mockup as a product screenshot.
- Enable Google Drive™ API and verify `userinfo.email` and `drive.file` scopes match the HTTP deployment, OAuth consent, and Marketplace configuration.
- Verify the file-access flow and successful Google Drive™ API metadata response with a fresh test account.
- Provide Google reviewers an isolated test account or reviewer self-service signup, plus an English screen recording that demonstrates the file-access and short-link flow. Do not share an owner password or API key.
- Submit the Public listing for Google review only after the live integration, permissions, and reviewer evidence are verified.
